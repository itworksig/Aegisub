# Aegisub macOS Apple Silicon Builds

This fork is only used to build Aegisub for macOS Apple Silicon Macs.

It tracks the upstream Aegisub repository:

`TypesettingTools/Aegisub`

The packaging branch is:

`macos-arm64-packaging`

GitHub Actions automatically syncs that branch from upstream and builds a native
macOS arm64 app bundle.

Release:

`Aegisub 3.4.1 macOS arm64`

Artifact:

`Aegisub.app.zip`

No Windows, Linux, Intel macOS, or DMG builds are maintained in this fork.
